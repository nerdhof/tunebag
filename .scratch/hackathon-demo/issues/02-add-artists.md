# 02: Add artists to the shared catalog

**What to build:** The listener adds several artist URLs and both devices show those artists' own uploads as catalog rows. No audio is downloaded.

**Blocked by:** 01: Pair two devices

**Status:** ready-for-agent

- [ ] Several artist URLs can be added in one step.
- [ ] Each artist contributes only that artist's own uploads.
- [ ] Each upload is a catalog row with title, duration, and source URL.
- [ ] The rows appear on the paired device after sync.
- [ ] Adding artists creates no audio files.
